# Cursor 설정 (백엔드 폴더)

이 저장소를 **단독으로** 열었을 때 과거에는 `.cursor/rules` 사본이 있었으나, **중복 제거**를 위해 제거되었다.

- **규칙 단일 소스**: 모노레포 루트의 [`.cursor/rules`](../../.cursor/rules) (워크스페이스에서 상위 폴더 `auto-investment-project`를 함께 연다).
- **MCP 템플릿**: 루트 [`.cursor/mcp.json.template`](../../.cursor/mcp.json.template) 를 복사해 로컬 `mcp.json`을 구성한다(저장소에 실제 `mcp.json`은 커밋하지 않음).

일상 개발은 **상위 저장소 루트** 또는 `auto-investment-project.code-workspace`로 여는 것을 권장한다.
