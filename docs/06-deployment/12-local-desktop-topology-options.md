# 로컬 데스크탑 토폴로지 포함 2안

로컬 PC(32GB RAM, i7-14700KF, RTX 4060 Ti 등)를 인프라 토폴로지에 포함할 때의 **설계 2안**을 정리한 문서다.  
**당장 세팅하지 않고**, 이후 로컬을 붙일 때 바로 찾아볼 수 있도록 요약만 둔다.

- **상세 설계·다이어그램·비교표**: Cursor Plan **§8 로컬 데스크탑 토폴로지 포함 2안**  
  - 계획 파일: `.cursor/plans/oracle_3대_배포_재설계_및_aws_검토_*.plan.md` 내 **## 8. 로컬 데스크탑 토폴로지 포함 2안** 참조.

---

## 요약

| 구분 | 안 1 (빌드·연산·개발 전용) | 안 2 (하이브리드 보조 노드) |
|------|----------------------------|-----------------------------|
| **프로덕션 경로** | 로컬 미포함. Oracle + AWS만. | 기본 동일. 로컬은 “있을 때만” 보조(헤비 연산 또는 개발용 app). |
| **로컬 역할** | 빌드(Self-hosted runner)·헤비 연산(백테스트/ML)·개발/스테이징 전체 스택. | 헤비 추론/배치 전용(Cloudflare Tunnel으로 AWS가 위임) 또는 개발 시 app만 로컬(hosts). |
| **가동** | 필수 아님. | 필수 아님. |
| **보안** | 로컬 공인 노출 없음. | 터널 사용 시 안전. |
| **권장** | **안정성·단순성 우선**이면 안 1. | 로컬 GPU/32GB를 **실서비스 연산에 쓸 때**만 안 2 검토. |

- **옵션**: 로컬에서 **prediction-service(GPU)·백테스트·모델 학습**을 두고, AWS는 **Backend + data-collector + nginx(api)** 만 두면 AWS 2GB 부담 감소·GPU 활용 가능.

---

## 로컬 스펙 (참고)

- CPU: Intel i7-14700KF  
- RAM: 32 GB  
- GPU: NVIDIA RTX 4060 Ti 8GB  
- 아키텍처: x64
