# Volume Spike Breakout — 당일 전략 설계

**목적**: **거래량 급증(Volume Spike)** 과 **가격 돌파(Breakout)** 를 동시에 만족할 때만 진입하는 당일(intraday) 퀀트 전략을 정의한다. 돌파만으로는 노이즈가 많으므로, **볼륨 확인**으로 신호 품질을 높인다.

**원칙**: 지표는 거래량·가격·시간만 사용. 파라미터 최소화·과적합 방지. PIT·Walk-Forward 검증 필수.

**관련 문서**: [16-kr-intraday-strategy-design.md](./16-kr-intraday-strategy-design.md), [00-strategy-registry.md](./00-strategy-registry.md), [14-trading-window-quant.md](./14-trading-window-quant.md).

---

## 1. Strategy Overview

| 항목 | 내용 |
|------|------|
| **전략명** | Volume Spike Breakout (VSB) — 당일 |
| **시장** | 한국 주식(KOSPI/KOSDAQ) 또는 동일 논리로 다른 시장 적용 가능 |
| **타임프레임** | Intraday — 진입·청산 모두 당일 |
| **핵심 논리** | (1) **Breakout**: 가격이 정해진 저항선(Opening Range High 또는 전일 Range 기반 목표가)을 **상향 돌파**. (2) **Volume Spike**: 해당 봉(또는 누적 구간) 거래량이 **평균 대비 N배 이상**일 때만 진입. → “돌파 + 거래량 확인”으로 가짜 돌파(false breakout) 필터링. |
| **지표** | **가격**: Open, High, Low, Close. **거래량**: Volume. **기준선**: 전일 Range 또는 당일 Opening Range(M분). 복잡 지표(RSI, MACD 등) 없음. |
| **거래 윈도우** | 한국장: **09:00~10:00** 또는 **14:30~15:30** (KST). 유동성·변동성 유리 구간만. |
| **포지션** | 롱 전용(매수만). |
| **과적합 방지** | 볼륨 배수(2x 등), 돌파 계수(k), 손절% 등 **소수 파라미터**만 사용. 둥근 숫자·경제적 해석 가능 값 고정. |

## 2. Entry Condition

진입은 **볼륨 스파이크**와 **브레이크아웃** 조건을 **둘 다** 만족할 때만(종목당 당일 1회 권장).

### 2.1 Breakout (가격 돌파)

| 옵션 | 정의 | 권장 |
|------|------|------|
| **A. 전일 Range 기반** | **Target = 당일 시가(Open) + k × (전일 High − 전일 Low)**. **현재가 ≥ Target** 이면 돌파. | k = 0.5. 기존 ORB와 동일. |
| **B. Opening Range High** | 당일 **첫 M분**(예: 5~15분) 동안의 **고가 = OR_High**. **현재가 > OR_High** 이면 돌파. | M = 10분. 구간 내 유동성 확보 후 돌파만 인정. |

**단일 선택**: A 또는 B 중 하나만 사용. A는 데이터 단순(전일 OHLC만), B는 당일 실시간 봉 필요.

### 2.2 Volume Spike (거래량 급증)

| 항목 | 정의 |
|------|------|
| **기준 거래량** | **AvgVol = 과거 N일** 동일 시간대까지의 **평균 거래량**(또는 N일 평균 일일 거래량). PIT: 당일 종료 전이므로 “동일 시간대 누적”은 **전일·전전일 등 과거 일별 “해당 시각까지 누적”** 또는 **일일 거래량 평균**으로 근사. |
| **현재 거래량** | **CurrVol = 당일 00:00 ~ 현재 시각까지의 누적 거래량** (또는 최근 1봉/5분봉 거래량). |
| **조건** | **CurrVol ≥ λ × AvgVol**. **λ(람다) = 2.0** 권장. “평소의 2배 이상 거래량일 때만” 진입. |

**단순 구현**:  
- **일봉 기준 근사**: 당일은 아직 종료 전이므로, **전일 거래량**을 AvgVol 대용으로 쓰고, **당일 현재까지 누적 거래량**이 **전일 전체 거래량의 50% 이상**이면 “볼륨 가속”으로 간주하는 방식 가능.  
- **또는** 과거 20일 **일일 거래량 평균**을 AvgVol로 두고, **당일 현재까지 누적**이 **AvgVol × (경과시간비)** 대비 2배 이상이면 스파이크.  
- **최소 구현**: **당일 누적 거래량 ≥ 전일 거래량 × 0.5** (오전/오후 세션 중반쯤부터 신호 가능).

### 2.3 통합 진입 조건 (AND)

| # | 조건 |
|---|------|
| 1 | **시간** | 09:00~10:00 또는 14:30~15:30 (KST) 내. |
| 2 | **Breakout** | (A) 현재가 ≥ Open + k × 전일 Range **또는** (B) 현재가 > Opening Range High. |
| 3 | **Volume Spike** | CurrVol ≥ λ × AvgVol (λ = 2.0 권장). 또는 당일 누적 ≥ 전일 Volume × 0.5. |
| 4 | **유동성** | 유니버스: 최근 5일 평균 거래대금 ≥ 최소 거래대금(예: 300억). |
| 5 | **미진입** | 해당 종목 당일 본 전략 진입/청산 이력 없음. |

## 3. Exit Condition

| # | 규칙 | 설명 |
|------|------|------|
| 1 | **손절** | **현재가 ≤ Entry × (1 − stopPct)**. **stopPct = 0.5%** (0.005). |
| 2 | **시간 청산** | 세션 종료 전 N분(예: 15:20 KST) 도달 시 **무조건 청산**. 당일 청산. |
| 3 | **익절(선택)** | **현재가 ≥ Entry × (1 + targetPct)**. **targetPct = 1.0%**. 손익비 약 2:1. |
| 4 | **트레일링(선택)** | 진입 후 당일 고가 대비 **−0.3%** 하락 시 청산. PIT: 진입 이후 갱신된 고가만 사용. |

손절·시간 청산은 **필수**. 익절/트레일링 중 하나만 적용해 단순성 유지.

---

## 4. Position Sizing

| 항목 | 규칙 |
|------|------|
| **기준** | 1거래당 **총자산의 R%** 위험. **R = 1%** 권장. |
| **수량** | **RiskAmount = TotalCapital × R**. **StopDistance = Entry × stopPct**. **Quantity = RiskAmount / StopDistance** (주식 단위 절사). |
| **상한** | 1종목당 총자산 **5%** 초과 금지. |
| **동시 포지션** | 당일 최대 **2~3종목**. |

---

## 5. Risk Management

| 구분 | 내용 |
|------|------|
| **일일 손실 한도** | 당일 누적 손실 **시초 평가액 대비 −2%** 도달 시 **당일 신규 진입 중단**. 기존 포지션은 손절/시간 청산만. |
| **최대 동시 포지션** | 2~3종목. |
| **Kill Switch** | 시스템 킬스위치 ON 시 모든 신규 진입 중단. |
| **유동성 필터** | 최소 거래대금 유니버스 유지. |
| **시간 제한** | 09:00~10:00, 14:30~15:30 외 진입 금지. |
| **검증** | Walk-Forward/OOS에서 Sharpe < 0.5 또는 MDD > 10% 시 미적용 또는 재검토. |

## 6. Expected Edge

| 근거 | 설명 |
|------|------|
| **Breakout + Volume** | 돌파만으로는 가짜 신호 많음. **거래량 급증**은 “참여 확대·정보 유입”을 의미해, 돌파의 **지속 가능성**이 높다는 실증·행동금융 관점. |
| **False breakout 필터** | 저거래량 돌파는 되돌림 가능성 큼. **λ ≥ 2** 로 “평소 대비 2배 이상”만 허용하면 노이즈 감소. |
| **단순·재현 가능** | OHLC + Volume + 전일 Range(또는 OR High)만 사용. 파라미터 최소 → 여러 시장·기간 검증·과적합 완화. |
| **당일 청산** | overnight 노출 없음. 손절·시간 청산으로 꼬리 리스크 절단. |

**목표(참고)**: 승률 45~55%, 손익비 1.5:1 이상, 연간 Sharpe 0.5~1.0. 수수료·세금·슬리피지 반영 백테스트 후 조정.

## 7. 파라미터 요약

| 파라미터 | 권장값 | 비고 |
|----------|--------|------|
| **Breakout** | k = 0.5 (A) 또는 OR 구간 M = 10분 (B) | 둘 중 하나 |

## 8. 데이터 요구사항

| 항목 | 내용 |
|------|------|
| **가격** | 당일 시가·고가·저가·현재가. 전일 High/Low/Close(또는 전일 Volume). |
| **거래량** | 당일 **누적 거래량**(시각별 또는 봉별). 과거 N일 **일일 거래량**(또는 동일 시각까지 누적). |
| **실시간** | Opening Range 사용 시 당일 **분봉/초단위 봉** 또는 틱 집계 필요. 전일 Range만 쓰면 **일봉 + 당일 시가·현재가**만으로 가능. |
