# 한국 주식 당일매매 전략 설계 (KR Intraday)

**목적**: 한국 시장·당일(intraday) 타임프레임용 **견고하고 과적합을 피하는**, 단순 지표 기반 퀀트 전략을 정의한다.

**원칙**: 지표는 최소한으로, 파라미터는 둥근 숫자·경제적 해석 가능한 값만 사용. 백테스트 시 PIT·Walk-Forward·Out-of-sample 검증 필수.

**관련 문서**: [00-strategy-registry.md](./00-strategy-registry.md), [14-trading-window-quant.md](./14-trading-window-quant.md).

---

## 1. Strategy Overview

| 항목 | 내용 |
|------|------|
| **전략명** | KR Intraday Opening Range Breakout (ORB) |
| **시장** | 한국 주식 (KOSPI/KOSDAQ) |
| **타임프레임** | 당일(intraday) — 진입·청산 모두 당일 내 |
| **논리** | 개장(또는 오후 구간) 초반 형성된 **가격 범위(Opening Range)** 를 돌파할 때 추세 추종. 유동성·시간대 필터로 노이즈·한산 구간 회피. |
| **지표** | 시가(Open), 고가(High), 저가(Low), 종가(Close), **전일 범위(Range = 전일 High − 전일 Low)** 만 사용. 추가로 **당일 시가 대비 범위** 또는 **N분 봉 범위** 하나만 사용 가능. (RSI/볼린저 등 복잡 지표 없음) |
| **거래 윈도우** | 한국장 유리 구간만: **09:00~10:00** 또는 **14:30~15:30** (KST). 그 외 구간 진입 금지. |
| **포지션** | 롱 전용(매수만). 공매도 미가정. |
| **과적합 방지** | (1) 파라미터 수 최소 (k, 손절%, 유동성 임계값 등). (2) k는 0.3~0.7 구간에서 고정(예: 0.5) 또는 시장 변동성 구간별 2~3단계만. (3) Walk-Forward·OOS 검증 없이 실전 적용 금지. |

## 2. Entry Condition

진입은 **다음 조건을 모두 만족할 때만** 1회(종목당 당일 1회 권장).

| # | 조건 | 설명 |
|---|------|------|
| 1 | **시간** | 현재 시각(KST)이 **09:00~10:00** 또는 **14:30~15:30** 구간 내. |
| 2 | **목표가 돌파** | 현재가 ≥ **Target**,  
  **Target = 당일 시가(Open) + k × 전일 범위(Range_prev)**  
  **Range_prev = 전일 High − 전일 Low**.  
  k는 고정 0.5 권장. (동적 조정 시 0.3~0.7, 변동성 구간별 2~3단계만) |
| 3 | **유동성** | 해당 종목이 **유니버스** 통과:  
  - 최근 5일 평균 거래대금 ≥ **최소 거래대금**(예: 300억 원, 시초가 구간)  
  - 또는 당일 예상 유동성(전일 거래대금 등)으로 프리필터. |
| 4 | **전일 범위 유효** | Range_prev > 0 이고, **이상치 제외**: 전일 범위가 전일 종가 대비 비율로 극단적(예: >15%)이면 스킵 가능(선택). |
| 5 | **미진입** | 해당 종목 당일 이미 본 전략으로 진입·청산했으면 재진입 금지. |

**단순 지표만 사용**: 시가, 전일 고/저(→ Range), 당일 시가. **이동평균·RSI·MACD·볼린저 등 사용하지 않음.**

## 3. Exit Condition

청산은 **아래 중 먼저 도달한 시점**에서 실행.

| # | 규칙 | 설명 |
|---|------|------|
| 1 | **손절 (Stop Loss)** | **현재가 ≤ Entry × (1 − stopPct)**.  
  **stopPct = 0.5%** (0.005) 권장. 단일 파라미터, 과도한 튜닝 금지. |
| 2 | **시간 청산 (Time Stop)** | **현재 시각이 해당 세션 종료 전 N분**(예: 15:20 KST) 이내이면 **무조건 청산**. 당일 청산 원칙. |
| 3 | **익절 (Take Profit, 선택)** | **현재가 ≥ Entry × (1 + targetPct)** 이면 청산.  
  **targetPct = 1.0%** (0.01) 권장. 손익비 2:1 근처 유지(0.5% 손절 대비 1% 익절). |
| 4 | **트레일링 스탑 (선택·단순)** | 진입 후 **당일 고가 대비 -0.3%** 하락 시 청산.  
  구현 시 “당일 고가”는 진입 이후 갱신되는 고가만 사용(PIT 준수). |

**우선순위**: 손절/시간 청산은 **필수**. 익절·트레일링은 전략 변형으로 추가 시 하나만 적용해 단순성 유지.

## 4. Position Sizing

| 항목 | 규칙 |
|------|------|
| **기준** | **리스크 기반**: 1거래당 **총자산의 R%** 를 위험 금액으로 한도. |
| **R** | **R = 0.5% ~ 1.0%** (예: 1%). 과도한 레버리지 방지. |
| **수량 계산** |  
  **RiskAmount = TotalCapital × R**  
  **StopDistance = Entry × stopPct** (Entry − Stop 가격 차이)  
  **Quantity = RiskAmount / StopDistance** (소수점 버림 후 주식 단위로 조정) |
| **상한** | 1종목당 **총자산의 5%** 초과 금지(집중 리스크 방지). |
| **동시 포지션** | 당일 **최대 2~3종목**까지. 그 이상 분산은 당일 매매에서는 관리 복잡도·슬리피지 증가. |

**단순 유지**: Kelly·변동성 역가중 등은 전략 확장 단계에서만 검토. 초기에는 고정 R% + 종목당 상한만 적용.

## 5. Risk Management

| 구분 | 내용 |
|------|------|
| **일일 손실 한도** | 당일 누적 손실이 **시초 평가액 대비 -2%** (또는 -1.5%) 도달 시 **당일 신규 진입 중단**. 기존 포지션은 손절/시간 청산 규칙대로만 청산. |
| **최대 동시 포지션** | 2~3종목. 초과 시 신규 진입 불가. |
| **Kill Switch** | 시스템 킬스위치(전체 주문 중단) 활성화 시 진입·추가 매수 불가. |
| **유동성 필터** | 유니버스: 최소 거래대금 충족 종목만. 슬리피지·미체결 리스크 감소. |
| **시간 제한** | 09:00~10:00, 14:30~15:30 외 구간 진입 금지 → 한산·노이즈 구간 회피. |
| **백테스트 검증** | Walk-Forward 또는 OOS 기간에서 **Sharpe &lt; 0.5** 또는 **MDD &gt; 10%** 이면 전략 미적용 또는 파라미터 재검토. |

## 6. Expected Edge

| 근거 | 설명 |
|------|------|
| **모멘텀 지속성** | 개장(또는 오후) 초반 돌파 구간에서 **단기 모멘텀**이 어느 정도 지속된다는 실증 연구·행동금융 관점. “돌파 = 신호”를 단순 규칙으로만 사용해 과적합을 줄임. |
| **비용·슬리피지 통제** | 유동성 필터 + 유리 시간대만 거래 → 체결 비용·슬리피지 완화. 당일 청산으로 overnight 노출 없음. |
| **손절·시간 청산** | 고정 손절·시간 청산으로 **꼬리 리스크** 절단. “왜 거래했는지” 설명 가능. |
| **파라미터 최소화** | k, stopPct, targetPct, R, 유동성 임계값 등 **소수 파라미터**만 사용 → 여러 기간·시장에서 재검증 가능, 과적합 완화. |
| **한국장 구조** | 09:00~10:00(시초가·기관/외인 포지션), 14:30~15:30(종가 수급) 구간은 상대적으로 **유동성·변동성**이 높아 단기 돌파 전략이 기대값이 나올 가능성이 있는 구간으로 가정. |

**기대 성과(참고)**  
- 목표: **승률 45~55%**, **손익비 1.5:1 이상**, **연간 Sharpe 0.5~1.0** (백테스트·OOS 검증 후 조정).  
- 실전에서는 수수료·세금·슬리피지 반영 후 **CAGR·MDD·Sharpe**를 재측정하고, 열화 시 거버넌스에 따라 축소 또는 중단.
