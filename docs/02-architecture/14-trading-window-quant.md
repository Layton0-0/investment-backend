# 퀀트 매매 유리 시간대 (Trading Window)

## 개요

핵심 질문은 **"언제 거래할 것인가?"가 아니라 "언제 알파가 존재하는가?"**이다. 한국·미국 시장별로 **유동성·변동성·스프레드**가 퀀트 매매에 유리한 구간이 다르다. 해당 시간대에만 진입·청산을 실행하고, 그 외에는 실행하지 않는다(치고 빠지는 구조).

**전략 유형 원칙**
- **변동성 기반 전략**(모멘텀/브레이크아웃 단타 등) → **활발한 시간대에만** 집중. 기대값·체결 비용 대비 효율이 높다.
- **왜곡 기반 전략**(통계 차익·페어 트레이딩·시장중립 등) → **상시 운용** 가능. 알파는 시간대보다 가격 왜곡에서 발생한다.

현재 시스템은 단기/중기/장기 모두 동일 트레이딩 윈도우(유리 구간만)를 적용한다. 향후 왜곡 기반 전략 도입 시 상시 운용 옵션(시간 필터 무시) 확장 가능.

## 한국장 (KR, KST)

| 구간 | 시간(KST) | 근거 |
|------|-----------|------|
| **유리 1** | 09:00 ~ 10:00 | 개장 직후. 시초가·변동성 돌파, 전일 미국장 반영·기관/외인 포지션 구축·거래대금·체결강도 집중. |
| **한산** | 11:30 ~ 14:00 | 점심 전후. 단타 기대값 급감, 노이즈 비중 증가. 이 구간 단타는 통계적으로 불리할 가능성 높음. |
| **유리 2** | 14:30 ~ 15:30 | 마감 1시간·종가 동시호가 포함. ETF 리밸런싱·종가 관리 수급·변동성·체결 강도 큼. |

**설정**: `investment.pipeline.trading-window.kr.start` / `.end` (1구간 09:00, 10:00), `kr.start2` / `kr.end2` (2구간 14:30, 15:30). KST 기준. start2/end2 미설정 시 1구간만 사용(하위 호환).

## 미국장 (US, NYSE/NASDAQ 정규장)

| 구간 | 시간(KST) | 근거 |
|------|-----------|------|
| **유리 1** | 23:30 ~ 01:00 | 개장 직후. overnight 갭 반영·숏커버링·뉴스 소화·변동성 폭발 구간. |
| **유리 2** | 05:00 ~ 06:00 | 마감 직전(KST 기준, 서머타임에 따라 1시간 변동 가능). |
| 비유리 | 그 외 | 프리마켓·애프터마켓은 스프레드·슬리피지 불리. 단, 미국장은 하루 종일 거래량이 비교적 유지되며 옵션/ETF/기관 알고리즘 비중이 높다. |

**설정**: `investment.pipeline.trading-window.us.start` / `.end` (1구간 23:30, 01:00), `us.start2` / `us.end2` (2구간 05:00, 06:00). KST 기준.

## VWAP·리버전 비고

VWAP 리버전 등은 **장중 내내** 실행 가능하나, 유동성이 적은 시간대(한국 11:30~14:00 등)에서는 **체결 비용 증가** 가능성이 있으므로 비중·슬라이스 설계 시 유리 구간 가중을 권장한다.

## 구현 요약

- **TradingWindowService**: `getKrSegments()` / `getUsSegments()`로 다중 구간 지원. `isInKrWindow()` / `isInUsWindow()`는 현재 시각(KST)이 **어느 세그먼트에라도** 포함되면 true.
- **PipelineExecutionScheduler**: 09:10(배치)·14:35 KR 전용(`runKrAfternoon`)·05:05 US 전용(`runUsClose`)에 실행. 각각 해당 윈도우 내일 때만 run 수행.
- **변동성 구간 회피**: `avoidVolatileWindow` true 시 9:00–9:10, 15:20–15:30(KR), 23:30–23:40, 05:50–06:00(US)에서 **신규 매수만 지연**(청산은 기존대로).
- 수동 트리거 시에도 동일: 허용 시간대가 아니면 해당 시장 run 스킵, 로그에 `OUTSIDE_TRADING_WINDOW` 기록.

## 시간대별 백테스트 설계 (참고)

시간대별 기대값 검증을 위해 아래 방식을 권장한다.

- **한국/미국 각각** 일봉 또는 **30분/1시간 봉** 단위로 수익률·샤프·슬리피지(체결 비용)를 집계한다.
- **유리 구간**(한국 09~10, 14:30~15:30 / 미국 23:30~01:00, 05:00~06:00 KST) vs **한산 구간**(한국 11:30~14:00 등)을 구분해, 구간별 승률·평균 수익·거래 비용을 비교한다.
- Walk-Forward 또는 일자별 백테스트 시 **실제 진입 허용 시간대**만 사용하려면, 백테스트 루프에서 “해당 일자·해당 시각이 트레이딩 윈도우 세그먼트에 포함되는가?”를 마스크로 적용한 뒤, 포함되는 시각에만 매수/매도로 집계한다. (예: 한국 1봉 = 09:00~09:30이면 1구간 포함 → 진입 허용; 12:00~12:30이면 미포함 → 해당 봉 진입 스킵.)

이를 통해 “어느 시간대에 알파가 있는지”를 수치로 확인하고, 트레이딩 윈도우 설정을 데이터 기반으로 조정할 수 있다.
