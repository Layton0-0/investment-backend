# 퀀트 매매 유리 시간대 (Trading Window)

## 개요

한국·미국 시장별로 **유동성·변동성·스프레드**가 퀀트 매매에 유리한 구간이 다르다. 해당 시간대에만 진입·청산을 실행하고, 그 외에는 실행하지 않는다(치고 빠지는 구조).

## 한국장 (KR, KST)

| 구간 | 시간(KST) | 근거 |
|------|-----------|------|
| **유리** | 09:00 ~ 10:00 (또는 10:30) | 시초가·변동성 돌파 구간. 거래대금·체결강도 집중, 슬리피지 상대적으로 낮음. 전략 명세(12-auto-investment-strategy)에서 "한국장 9:00~10:00 변동성 반영" 명시. |
| 비유리 | 10:30 ~ 15:30 | 점심 시간 전후 거래량·유동성 분산, 스프레드 확대 가능. |

**설정**: `investment.pipeline.trading-window.kr.start` / `.end` (기본 09:00, 10:00). KST 기준.

## 미국장 (US, NYSE/NASDAQ 정규장)

| 구간 | 시간(KST) | 근거 |
|------|-----------|------|
| **유리** | 21:30 ~ 23:00 (개장 ~ 약 1.5시간) | 미 정규장 개장(EST 09:30 = KST 23:30 동절기 / 22:30 하절기). 개장 1시간 전후 유동성·볼륨 집중, VWAP·TWAP 실행에 유리. |
| 비유리 | 그 외 | 프리마켓·애프터마켓은 스프레드·슬리피지 불리. |

**참고**: KST 21:30 = EST 07:30 (동절기) → 미 정규장은 EST 09:30 = KST 23:30. 따라서 **US 유리 구간을 KST 23:30~01:00**으로 두는 것이 정확하나, 국내 브로커·API 연동 시점을 고려해 **21:30~23:00**을 “진입 준비·주문 투하 허용” 구간으로 두고, 실제 미 장 개장 직후(23:35 KST 등)에 실행하도록 할 수 있다. 설정으로 조정.

**설정**: `investment.pipeline.trading-window.us.start` / `.end` (기본 21:30, 23:00). KST 기준. (미 장 개장 23:30 반영 시 23:30~01:00 등으로 변경 가능.)

## 구현 요약

- **PipelineExecutionScheduler**: 현재 시각(KST)이 시장별 허용 구간 안일 때만 해당 시장 KR/US run 실행.
- **한국**: 기존 auto-buy cron 09:10 → KR 윈도우 내이므로 KR만 실행, US는 윈도우 밖이므로 스킵.
- **미국**: 별도 cron 21:35(또는 23:35)에 “파이프라인 US만” 실행하는 Job(예: auto-buy-us) 실행 → US 윈도우 내에서만 US 전략 실행.
- 수동 트리거 시에도 동일: 허용 시간대가 아니면 해당 시장 run 스킵, 로그에 `OUTSIDE_TRADING_WINDOW` 등으로 기록.
