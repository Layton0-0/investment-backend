# 수치 기반 정량적 투자 전략 아키텍처

## 개요

AI가 아닌 **수치 기반 규칙 엔진**과 **거시경제 지표 기반 전략**을 사용하여
거시경제 전략가 및 투자 자산 운용 총괄이 직접 투자하듯이 시스템을 설계했습니다.

## 핵심 원칙

1. **AI는 분석 정보 제공용으로만 사용**
   - AI 예측은 참고 정보로만 활용
   - 최종 투자 결정은 수치 기반 규칙으로 수행

2. **명확한 수치 기준과 공식**
   - 모든 결정은 수치 기반 점수 계산
   - 투명하고 재현 가능한 규칙

3. **거시경제 관점**
   - 금리, 인플레이션, GDP, VIX 등 거시경제 지표 기반
   - 시장 레짐 판단 및 자산 배분

## 주요 컴포넌트

### 1. MacroEconomicStrategyEngine (거시경제 전략 엔진)

**역할**: 거시경제 지표를 기반으로 투자 전략을 결정

**입력**:
- VIX (변동성 지수)
- 금리
- 인플레이션율
- GDP 성장률
- 실업률
- 달러 인덱스 (DXY)
- 유가, 금 가격

**출력**:
- 시장 레짐 (Market Regime)
- 리스크 레벨 (0.0 ~ 1.0)
- 자산 배분 전략 (주식/채권/현금 비율)
- 포지션 사이징
- 타이밍 전략

**시장 레짐 예시**:
- HIGH_VOLATILITY: VIX > 30
- RECESSION: GDP 성장률 < 0
- GROWTH: GDP 성장률 > 3%
- HIGH_INTEREST_RATE: 금리 > 5%

### 2. QuantitativeRuleEngine (정량적 규칙 엔진)

**역할**: 수치 기반 규칙으로 매수/매도/보유 결정

**점수 계산 방식**:
1. **RSI 점수** (가중치: 20%)
   - RSI < 30: 1.0 (과매도, 강한 매수 신호)
   - RSI > 70: 0.0 (과매수, 강한 매도 신호)
   - 30 ≤ RSI ≤ 70: 선형 보간

2. **MACD 점수** (가중치: 25%)
   - MACD > Signal: 상승 신호
   - 히스토그램 크기에 따라 점수 조정

3. **EMA 점수** (가중치: 20%)
   - 골든크로스: 1.0
   - 데드크로스: 0.0
   - 정렬 상태에 따라 점수 부여

4. **거래량 점수** (가중치: 15%)
   - 거래량 증가율 150% 이상: 1.0
   - 거래량 증가율 50% 이하: 0.0
   - 선형 보간

5. **VWAP 점수** (가중치: 10%)
   - 현재가 > VWAP * 1.05: 1.0
   - 현재가 < VWAP * 0.95: 0.0
   - 선형 보간

6. **거시경제 조정** (가중치: 10%)
   - 리스크 레벨에 반비례

**결정 규칙**:
- 총점 ≥ 0.7: **매수**
- 총점 ≤ 0.3: **매도**
- 0.3 < 총점 < 0.7: **보유**

### 3. AnalysisService (분석 서비스)

**역할**: AI와 기술적 분석을 결합하여 분석 정보 제공

**중요**: 
- AI는 **분석 정보 제공용으로만** 사용
- **최종 결정은 하지 않음**
- `recommendation`은 "ANALYSIS_ONLY"로 설정

## 데이터 흐름

### 거래 결정 프로세스

```
1. TradingStrategyService.decideTradingAction()
   │
   ├─► StockAnalysisService.analyzeStock()
   │   └─► 기술적 지표 수집 (RSI, MACD, EMA, VWAP 등)
   │
   ├─► MacroEconomicStrategyEngine.decideStrategy()
   │   └─► 거시경제 지표 기반 전략 결정
   │
   └─► QuantitativeRuleEngine.decide()
       ├─► 점수 계산 (RSI, MACD, EMA, 거래량, VWAP, 거시경제)
       ├─► 결정 타입 결정 (매수/매도/보유)
       ├─► 가격 레벨 계산 (진입가, 손절가, 목표가)
       └─► 포지션 사이즈 계산
       │
       └─► TradingDecision 반환
           │
           └─► OrderRequestDto 생성 (매수/매도인 경우)
```

## 수익 공식

### 포지션 사이즈 계산
```
포지션 사이즈 = (기술적 점수 × 10% + 거시경제 포지션 사이즈) / 2
최소: 2%, 최대: 20%
```

### 손익 계산
```
손익 = (매도가 - 매수가) × 수량
수익률 = (손익 / 투자금액) × 100%
```

### 리스크/리워드 비율
```
R:R = (목표가 - 진입가) / (진입가 - 손절가)
목표: R:R 2:1 이상
```

## 거시경제 지표 수집 (향후 구현)

현재는 기본값을 사용하지만, 향후 다음 API를 통해 실제 데이터를 수집해야 합니다:

1. **VIX**: CBOE API 또는 Yahoo Finance
2. **금리**: FRED (Federal Reserve Economic Data) API
3. **인플레이션**: FRED API
4. **GDP**: FRED API
5. **DXY**: Forex API
6. **유가/금가**: Commodity API

## 장점

1. **투명성**: 모든 결정이 명확한 수치 기준에 기반
2. **재현성**: 동일한 입력에 대해 항상 동일한 결과
3. **설명 가능성**: 결정 근거를 명확히 설명 가능
4. **제어 가능**: 규칙을 수정하여 전략 조정 가능
5. **AI 의존성 낮음**: AI 서비스 장애 시에도 기술적 분석만으로 동작 가능

## AI 활용 범위

- **분석 정보 제공**: 가격 예측, 변동성 예측 등
- **의사결정은 하지 않음**: 최종 매수/매도 결정은 수치 기반 규칙 엔진에서 수행

## 향후 개선 사항

1. **실제 거시경제 지표 수집 API 연동**
2. **백테스팅 엔진**: 과거 데이터로 규칙 검증
3. **규칙 최적화**: Genetic Algorithm 등으로 규칙 파라미터 최적화
4. **포트폴리오 최적화**: Mean-Variance Optimization 등
5. **동적 규칙 조정**: 시장 레짐에 따른 규칙 파라미터 자동 조정
