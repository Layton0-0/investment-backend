# 연말 세금·리포트 명세

**목적**: 투자 실현손익·배당 소득에 대한 연말 세금 추정 및 리포트 기능 명세

---

## 1. 기능 개요

### 1.1 지원 기능
- **국내 실현손익 집계**: 한국투자증권 기간별손익조회 API 기반
- **예상 세금 계산**: 기본공제 적용 후 가정 세율 적용
- **CSV/PDF 내보내기**: UTF-8 BOM CSV, PDF 다운로드

### 1.2 미지원 기능 (후속 구현 예정)
- **해외 실현손익**: 별도 API 연동 필요
- **배당 소득 수집**: 증권사 API 또는 수동 입력
- **Hometax 연동**: 국세청 API 또는 수동 업로드 플로우

---

## 2. 세금 계산 가정

### 2.1 국내 주식 양도소득세 (가정)
```
과세대상 = 실현손익 - 기본공제(250만원)
예상 세금 = 과세대상 × 22% (양도소득세 20% + 지방소득세 2%)
```

### 2.2 기본 공제
| 항목 | 금액 |
|------|------|
| 연간 기본공제 | 2,500,000원 |

**주의**: 
- 대주주 요건(종목별 10억 이상)은 미반영
- 코스피/코스닥 상장주식 기준
- 비상장·장외거래·파생상품은 별도 세율 적용 필요

### 2.3 적용 세율 (가정)
| 구분 | 세율 | 비고 |
|------|------|------|
| 국내 주식 (비대주주) | 22% | 양도세 20% + 지방세 2% |
| 해외 주식 | 22% | 양도세 20% + 지방세 2%, 250만원 공제 |
| 배당 소득 | 15.4% | 소득세 14% + 지방세 1.4% |

---

## 3. 가정·제한·면책

### 3.1 시스템 가정
1. **데이터 출처**: 한국투자증권 기간별손익조회 API만 사용
2. **실현손익 기준**: API 반환값 그대로 합산 (별도 검증 없음)
3. **기본공제**: 연간 250만원 일괄 적용 (분할 적용 미지원)
4. **세율**: 비대주주 단일 세율 22% 가정

### 3.2 제한사항
1. **대주주 판정 미지원**: 종목별 보유금액 10억원 이상 여부 미판정
2. **다중 증권사 미지원**: 한국투자증권 계좌만 집계
3. **손실 이월공제 미지원**: 전년도 손실 이월 반영 없음
4. **해외주식 환전손익 미포함**: 환차손익은 별도 산정 필요
5. **배당소득 미집계**: 현재 버전에서는 수동 입력 필요

### 3.3 면책 조항
> **본 서비스에서 제공하는 세금 정보는 참고용 추정치이며, 세무 자문이나 법률 조언이 아닙니다.**
> 
> - 실제 세금 신고는 반드시 **국세청 홈택스**에서 확인하시기 바랍니다.
> - 정확한 세금 계산을 위해서는 **세무사 또는 전문가 상담**을 권장합니다.
> - 본 서비스는 계산 오류에 대한 책임을 지지 않습니다.

## 4. API 명세

### 4.1 세금 요약 조회
```
GET /api/v1/report/tax/summary?year=2026
Authorization: Bearer {token}
```

**응답**:
```json
{
  "year": 2026,
  "domesticRealizedGainLoss": 5000000,
  "overseasRealizedGainLoss": null,
  "dividendTotal": null,
  "basicDeduction": 2500000,
  "taxableAmount": 2500000,
  "estimatedTax": 550000,
  "disclaimer": "본 내용은 추정이며 세무 자문이 아닙니다..."
}
```

### 4.2 내보내기
```
GET /api/v1/report/tax/summary/export?year=2026&format=csv
GET /api/v1/report/tax/summary/export?year=2026&format=pdf
Authorization: Bearer {token}
```
