# 종목·지수 코드(code 폴더) 명세

원본 경로: `investment-backend/docs/korea-investment-api/code/`

API 파라미터(종목코드·거래소코드·지수코드 등) 검증 시 아래 파일을 참조하거나, 한국투자증권 MCP로 확인한다.

## 1. 국내 종목코드 (고정폭 텍스트 .mst)

| 파일 | 설명 | 용도 |
|------|------|------|
| kospi_code.mst | 코스피 종목코드 | 국내 유가증권시장(코스피) 상장 종목 코드. 고정폭 텍스트 포맷. API 요청 시 PDNO 등에 6자리 사용. |
| kosdaq_code.mst | 코스닥 종목코드 | 코스닥 시장 상장 종목 코드. 고정폭 텍스트. 6자리 종목코드. |
| konex_code.mst | 코넥스 종목코드 | 코넥스 시장 상장 종목 코드. 고정폭 텍스트. |
| elw_code.mst | ELW 종목코드 | ELW(주식워런트) 종목 코드. ELW 시세·주문 API의 종목 파라미터 검증 시 참조. |

**의미**: 각 레코드는 종목코드(또는 단축코드)·종목명·시장구분 등 고정 길이 필드로 구성된다. 파싱 시 한국투자증권 Github 또는 포털 문서의 정제 코드/레코드 레이아웃을 참조.

---

## 5. 사용 시 유의사항

- **인코딩**: .mst/.COD 파일 인코딩(예: EUC-KR, UTF-8)은 한국투자증권 제공 명세 또는 샘플 파싱 코드 기준으로 확인.
- **갱신**: 코드 파일은 거래소·상장 변동에 따라 주기적으로 갱신될 수 있음. 배치/수집 경로에서 버전 관리 시 파일명·일자 확인.
- **공개 저장소**: 코드 파일 내용에 민감정보가 없도록 하며, 필요 시 .gitignore 대상으로 두고 빌드/배포 시점에만 주입.
