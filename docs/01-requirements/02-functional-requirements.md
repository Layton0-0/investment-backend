# 기능 요구사항

## 0. 자동투자·시장·뉴스 연동 (고수준)

- **자동투자수익**: 사람 개입 없이 4단계 파이프라인(유니버스→시그널→자금관리→매매실행) 기반 자동 매매로 수익 극대화.
- **시장(Market)**: 국내(KR, KOSPI/KOSDAQ)·미국(US, NYSE/NASDAQ) 구분. 전략·유니버스·시그널은 시장별·분류별로 상이한 알고리즘 적용.
- **전략(시장+기간)**: 전략 타입(SHORT_TERM, MEDIUM_TERM, LONG_TERM)과 시장(KR/US) 조합으로 관리. 단기/중기/장기 비중·필터·손절 규칙은 시장별로 다르게 운영.
- **뉴스·공시 조회/연동**: 확정 원천만 파이프라인 연결.
  - **한국**: Fact = DART(Open API), Speed = 연합뉴스(Yonhap), Buzz = 네이버 금융(Naver). DART Real-time Push 권장.
  - **미국**: Fact = SEC EDGAR(API), Speed = Reuters(로이터), Buzz = Yahoo Finance. 8-K 발생 시 최우선 순위 로직 실행.
- **확장성**: 새 시장·새 분류·새 메뉴 추가 시 기존 구조를 깨지 않고 확장 가능하도록 설계.

**상세**: [자동투자 전략 명세](../02-architecture/12-auto-investment-strategy.md), [뉴스·공시 수집·연동 설계](../02-architecture/13-news-collection-design.md)

## 1. 계좌 관리

### 1.1 계좌 잔고 조회
- **기능**: 한국투자증권 계좌의 현재 잔고 정보를 조회합니다. 한국투자증권 Open API를 사용하여 실시간 잔고 정보를 조회합니다.
- **입력**: 계좌번호
- **출력**: 
  - 예수금
  - 주문가능금액
  - 총 평가금액
  - 총 손익
- **API**: `GET /api/v1/accounts/{accountNo}/balance`

### 1.2 보유 종목 조회
- **기능**: 계좌에 보유 중인 종목 목록을 조회합니다. 한국투자증권 Open API를 사용하여 실시간 보유 종목 정보를 조회합니다.
- **입력**: 계좌번호
- **출력**:
  - 종목 코드
  - 종목명
  - 보유 수량
  - 평균 매수가
  - 현재가
  - 평가금액
  - 평가손익
- **API**: `GET /api/v1/accounts/{accountNo}/positions`

## 2. 주문 관리

### 2.1 주문 실행
- **기능**: 주식 매수/매도 주문을 실행합니다.
- **입력**:
  - 계좌번호
  - 종목 코드
  - 주문 유형 (매수/매도)
  - 수량
  - 가격
- **검증**:
  - 최대 투자금액 초과 여부
  - 최소 투자금액 미만 여부
  - 계좌 잔고 확인
- **출력**: 주문 ID, 주문 상태
- **API**: `POST /api/v1/orders`

### 2.2 주문 조회
- **기능**: 특정 주문의 상세 정보를 조회합니다.
- **입력**: 주문 ID, 계좌번호
- **출력**:
  - 주문 정보
  - 체결 수량
  - 체결 가격
  - 주문 상태
- **API**: `GET /api/v1/orders/{orderId}?accountNo={accountNo}`

### 2.3 주문 목록 조회
- **기능**: 계좌의 주문 목록을 조회합니다.
- **입력**: 계좌번호 (선택: 기간, 상태)
- **출력**: 주문 목록
- **API**: `GET /api/v1/orders?accountNo={accountNo}`

### 2.4 주문 취소
- **기능**: 미체결 주문을 취소합니다.
- **입력**: 주문 ID, 계좌번호
- **제약**: 체결된 주문은 취소 불가
- **API**: `DELETE /api/v1/orders/{orderId}?accountNo={accountNo}`

## 3. 종목 분석

### 3.1 종목 분석
- **기능**: 종목에 대한 기술적 분석을 수행하고 투자 추천을 제공합니다.
- **입력**:
  - 종목 코드
  - 분석 기간 (일)
- **분석 항목**:
  - RSI (상대강도지수)
  - MACD (이동평균수렴확산)
  - EMA (지수이동평균)
  - 볼린저 밴드
  - ATR (평균진폭)
  - VWAP (거래량가중평균가격)
- **출력**:
  - 추천 (매수/매도/보유)
  - 신뢰도 (0.0 ~ 1.0)
  - 현재가
  - 기술적 지표 값
- **API**: `POST /api/v1/analysis`

## 4. 전략 관리

### 4.1 전략 조회
- **기능**: 계좌의 투자 전략 목록을 조회합니다.
- **입력**: 계좌번호
- **출력**: 전략 목록 (전략 타입, 상태, 성과 등)
- **API**: `GET /api/v1/strategies/{accountNo}`

### 4.2 전략 상세 조회
- **기능**: 특정 전략의 상세 정보를 조회합니다.
- **입력**: 계좌번호, 전략 타입
- **출력**: 전략 상세 정보
- **API**: `GET /api/v1/strategies/{accountNo}/{strategyType}`

### 4.3 전략 생성
- **기능**: 새로운 투자 전략을 생성합니다. 시장(KR/US)과 전략 타입(단기/중기/장기) 조합으로 관리.
- **입력**:
  - 계좌번호
  - 시장 (KR, US) — 선택 시 해당 시장 유니버스·시그널·손절 규칙 적용
  - 전략 타입 (SHORT_TERM, MEDIUM_TERM, LONG_TERM)
  - 최대 투자금액
  - 최소 투자금액
  - 리스크 레벨
  - 신뢰도 임계값
- **출력**: 생성된 전략 정보
- **API**: `POST /api/v1/strategies`

### 4.4 전략 상태 변경
- **기능**: 전략의 상태를 변경합니다 (활성화/중지/일시정지).
- **입력**: 계좌번호, 전략 타입, 상태
- **상태**:
  - ACTIVE: 활성 (실행 중)
  - STOPPED: 중지됨
  - PAUSED: 일시 정지
- **API**: `PUT /api/v1/strategies/{accountNo}/{strategyType}/status`

### 4.5 전략 활성화
- **기능**: 중지된 전략을 활성화합니다.
- **API**: `POST /api/v1/strategies/{accountNo}/{strategyType}/activate`

### 4.6 전략 중지
- **기능**: 실행 중인 전략을 중지합니다.
- **API**: `POST /api/v1/strategies/{accountNo}/{strategyType}/stop`

## 5. 거래 설정 관리

### 5.1 거래 설정 조회
- **기능**: 계좌의 거래 설정을 조회합니다.
- **입력**: 계좌번호
- **출력**:
  - 최대 투자금액
  - 최소 투자금액
  - 기본 통화
  - 자동 매매 활성화 여부
  - 리스크 레벨
- **API**: `GET /api/v1/settings/{accountNo}`

### 5.2 거래 설정 저장/업데이트
- **기능**: 거래 설정을 저장하거나 업데이트합니다.
- **입력**: 거래 설정 정보
- **검증**:
  - 최대 투자금액 > 최소 투자금액
  - 리스크 레벨 범위 (0.0 ~ 1.0)
- **API**: `PUT /api/v1/settings/{accountNo}`

## 6. 트레이딩 포트폴리오

### 6.1 일별 트레이딩 포트폴리오 생성
- **기능**: 매일 거래일 시작 전에 일별 트레이딩 포트폴리오를 자동 생성합니다.
- **생성 내용**:
  - 시장 요약
  - 유망 섹터 TOP 3
  - 추천 종목 목록 (최대 5개)
  - 각 종목별:
    - 진입가 범위
    - 손절가
    - 목표가 1, 2
    - 기대 수익률
    - 리스크/리워드 비율
    - 기술적 근거
    - 수급 근거
    - 촉매 요인
    - 매수/매도 시간
- **실행 주기**: 매일 오전 9시 (스케줄러)

### 6.2 트레이딩 포트폴리오 조회
- **기능**: 특정 날짜의 트레이딩 포트폴리오를 조회합니다.
- **입력**: 거래일
- **출력**: 포트폴리오 상세 정보
- **API**: `GET /api/v1/trading-portfolios/{date}`

## 7. 웹 대시보드

### 7.1 대시보드
- **기능**: 계좌 정보, 보유 종목, 주문 현황을 한눈에 볼 수 있는 대시보드를 제공합니다.
- **URL**: `GET /?accountNo={accountNo}`

### 7.2 전략 관리 화면
- **기능**: 전략 목록 및 상태를 조회하고 관리할 수 있는 화면을 제공합니다.
- **URL**: `GET /strategies?accountNo={accountNo}`

### 7.3 포트폴리오 화면
- **기능**: 트레이딩 포트폴리오를 조회할 수 있는 화면을 제공합니다.
- **URL**: `GET /portfolio?date={date}`

## 8. 배치 작업

### 8.1 배치 작업 관리
- **기능**: 스케줄러로 실행되는 배치 작업을 관리합니다.
- **주요 배치**:
  - 전략 실행 스케줄러 (StrategyScheduler)
  - 트레이딩 포트폴리오 생성 스케줄러 (TradingPortfolioScheduler)
- **API**: `GET /batch/api/jobs` (실제 구현 경로. API 개요·엔드포인트 문서 참조.)
