# 프로젝트 개요

## 프로젝트명
Investment Choi - 주식 투자 수익 분석 및 자동 매매 시스템

## 프로젝트 목적
한국투자증권 Open API를 활용하여 주식 투자 수익 분석 및 자동 매매를 수행하는 시스템을 구축합니다.

## 주요 목표
1. **자동화된 투자 분석**: AI 기반 종목 분석 및 투자 추천
2. **전략 기반 자동 매매**: 다양한 투자 전략(단기/중기/장기)을 통한 자동 매매 실행
3. **리스크 관리**: 투자금액 제한, 손절가 설정 등을 통한 리스크 관리
4. **포트폴리오 관리**: 일별 트레이딩 포트폴리오 생성 및 관리
5. **실시간 모니터링**: 계좌 잔고, 보유 종목, 주문 현황 실시간 조회

## 대상 사용자
- 개인 투자자
- 퀀트 트레이더
- 자동 매매 시스템 운영자

## 프로젝트 범위

### 포함 사항
- 계좌 조회 및 관리
- 주문 실행 및 관리
- 종목 분석 및 추천
- 전략 기반 자동 매매
- 트레이딩 포트폴리오 생성
- 웹 대시보드 제공
- REST API 제공

### 제외 사항
- 실시간 시장 데이터 스트리밍 (현재는 폴링 방식)
- 다중 계좌 동시 관리 (향후 확장 가능)
- 옵션/선물 등 파생상품 거래
- 해외 주식 거래 (현재는 국내 주식 중심)

## 기술 스택
- **Backend**: Spring Boot 2.7.18 (Java 11)
- **Frontend**: Thymeleaf
- **Database**: MariaDB 11.8.5
- **Build Tool**: Gradle
- **API**: 한국투자증권 Open API
