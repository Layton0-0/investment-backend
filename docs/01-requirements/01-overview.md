# 프로젝트 개요

## 프로젝트명
Investment Choi - 주식 투자 수익 분석 및 자동 매매 시스템

## 프로젝트 목적
한국투자증권 KIS Developers (Open API)를 활용하여 **사람이 개입하지 않아도 되는 자동투자수익**을 목표로, 국내·미국 주식을 하나의 인터페이스로 통합 관리하는 시스템을 구축합니다.

## 주요 목표
1. **자동투자수익**: 사람 개입 없이 퀀트 엔진 기반 자동 매매로 수익 극대화 (MDD -15% 이내, CAGR 30%+ 목표)
2. **4단계 파이프라인**: 유니버스 선정 → 시그널 생성 → 자금 관리 → 매매 실행 (시장별·분류별 알고리즘 적용)
3. **국내·미국 통합**: 한국(KOSPI/KOSDAQ)·미국(NYSE/NASDAQ) 주식 단일 인터페이스·통합 증거금
4. **전략 기반 자동 매매**: 단기/중기/장기 전략을 시장별로 다르게 운영
5. **공시·뉴스·센티멘트 연동**: 확정 원천(DART·연합·네이버 / SEC·Reuters·Yahoo)만 파이프라인 연결
6. **리스크 관리**: 투자금액 제한, 손절가·ATR Trailing Stop, 켈리·변동성 역가중 등
7. **실시간 모니터링**: WebSocket 우선 시세·체결, 계좌·보유·주문 실시간 조회

## 대상 사용자
- 개인 투자자
- 퀀트 트레이더
- 자동 매매 시스템 운영자

## 프로젝트 범위

### 포함 사항
- 계좌 조회 및 관리 (국내·미국 통합 증거금)
- 주문 실행 및 관리 (한투 KIS API·WebSocket 우선)
- 종목 분석 및 추천 (시장별·분류별 알고리즘)
- 4단계 파이프라인 기반 자동 매매 (유니버스→시그널→자금관리→매매실행)
- 공시/데이터·뉴스/센티멘트 확정 원천만 파이프라인 연결
- 트레이딩 포트폴리오 생성
- 웹 대시보드 제공 (메뉴 확장 가능 구조)
- REST API 제공

### 제외 사항
- 다중 계좌 동시 관리 (향후 확장 가능)
- 옵션/선물 등 파생상품 거래
- 확정 원천 외 데이터 소스 파이프라인 연결 금지 (속도·정확도 확보)

## 기술 스택
- **Backend**: Spring Boot 3.2.2 (Java 17)
- **Frontend**: Thymeleaf (확장 가능 메뉴 구조)
- **Database**: MariaDB 11.8.5
- **Build Tool**: Gradle
- **API**: 한국투자증권 KIS Developers (Open API) — REST·WebSocket
