# 비기능 요구사항

## 1. 성능 요구사항

### 1.1 응답 시간
- **API 응답 시간**: 평균 500ms 이하, 95%ile 1초 이하
- **주문 실행 시간**: 2초 이하
- **종목 분석 시간**: 3초 이하
- **웹 페이지 로딩 시간**: 2초 이하

### 1.2 처리량
- **동시 사용자**: 최소 10명
- **초당 요청 처리**: 최소 50 TPS
- **일일 주문 처리**: 최소 1,000건

### 1.3 데이터 처리
- **시장 데이터 조회**: 초당 5회 제한 (키움증권 API 제약)
- **배치 작업 실행 시간**: 5분 이하

## 2. 가용성 요구사항

### 2.1 시스템 가동률
- **목표 가동률**: 99.0% 이상
- **계획된 다운타임**: 월 1회, 2시간 이내 (유지보수)

### 2.2 장애 복구
- **장애 감지 시간**: 5분 이내
- **복구 시간**: 30분 이내
- **데이터 복구**: 최대 1시간 전 상태로 복구 가능

## 3. 보안 요구사항

### 3.1 인증/인가
- **계좌 접근 제어**: 계좌번호 기반 접근 제어
- **API 키 관리**: 환경 변수 또는 시크릿 관리자 사용
- **비밀번호 암호화**: 평문 저장 금지

### 3.2 데이터 보안
- **개인정보 보호**: 계좌번호, 비밀번호 등 민감 정보 암호화
- **로그 마스킹**: PII(개인식별정보) 마스킹 처리
- **세션 정보**: 로그에 토큰/세션 ID 기록 금지

### 3.3 네트워크 보안
- **HTTPS**: 프로덕션 환경에서 HTTPS 필수
- **CORS**: 적절한 CORS 정책 설정
- **CSRF**: CSRF 보호 적용

## 4. 확장성 요구사항

### 4.1 수평 확장
- **무상태 설계**: 세션 상태를 서버에 저장하지 않음
- **로드 밸런싱**: 다중 인스턴스 배포 지원

### 4.2 데이터베이스 확장
- **인덱싱**: 자주 조회되는 컬럼에 인덱스 설정
- **파티셔닝**: 대용량 데이터 처리를 위한 파티셔닝 고려

## 5. 유지보수성 요구사항

### 5.1 코드 품질
- **코드 커버리지**: 라인 커버리지 80% 이상, 브랜치 커버리지 70% 이상
- **코드 리뷰**: 모든 변경사항에 대한 코드 리뷰 필수
- **정적 분석**: SonarQube 등 정적 분석 도구 사용

### 5.2 문서화
- **API 문서**: OpenAPI/Swagger 문서 자동 생성
- **코드 주석**: 복잡한 로직에 대한 주석 작성
- **아키텍처 문서**: 시스템 아키텍처 및 설계 문서 유지

### 5.3 로깅
- **구조화 로깅**: JSON 형식의 구조화된 로그
- **로그 레벨**: 환경별 적절한 로그 레벨 설정
- **로그 보관**: 최소 30일간 보관
- **로그 경로**: Kubernetes 환경에서 `/LOG` 경로 사용

## 6. 호환성 요구사항

### 6.1 플랫폼
- **운영체제**: Linux (Kubernetes 환경)
- **Java 버전**: Java 11 (SE)
- **데이터베이스**: MariaDB 11.8.5 이상

### 6.2 브라우저
- **지원 브라우저**: Chrome, Firefox, Edge (최신 2개 버전)

## 7. 모니터링 요구사항

### 7.1 메트릭
- **애플리케이션 메트릭**: 요청 수, 응답 시간, 에러율
- **비즈니스 메트릭**: 주문 수, 전략 실행 횟수, 수익률
- **인프라 메트릭**: CPU, 메모리, 디스크 사용률

### 7.2 알림
- **장애 알림**: 시스템 장애 시 즉시 알림
- **성능 저하 알림**: 응답 시간 임계값 초과 시 알림
- **비즈니스 알림**: 주문 실패, 전략 실행 실패 시 알림

### 7.3 헬스 체크
- **Health Endpoint**: `/actuator/health`
- **Liveness Probe**: 애플리케이션 생존 여부 확인
- **Readiness Probe**: 트래픽 수신 준비 여부 확인

## 8. 규정 준수 요구사항

### 8.1 금융 규정
- **자동 매매 규정**: 관련 금융 규정 준수
- **거래 기록**: 모든 거래 내역 기록 및 보관

### 8.2 데이터 보호
- **개인정보보호법**: 개인정보 처리 방침 준수
- **데이터 보관**: 법정 보관 기간 준수

## 9. 개발 환경 요구사항

### 9.1 로컬 개발
- **로컬 데이터베이스**: MariaDB 로컬 설치 또는 Docker
- **프로파일**: `local` 프로파일 지원
- **모의 데이터**: 개발/테스트용 모의 데이터 지원

### 9.2 테스트
- **단위 테스트**: JUnit5 + Mockito
- **통합 테스트**: Spring Boot Test Slice (@WebMvcTest, @DataJpaTest)
- **테스트 커버리지**: CI/CD 파이프라인에서 커버리지 검증

## 10. 배포 요구사항

### 10.1 컨테이너화
- **Docker**: Docker 이미지 빌드 및 배포
- **Kubernetes**: Kubernetes 환경에서 배포

### 10.2 CI/CD
- **자동 빌드**: 코드 푸시 시 자동 빌드
- **자동 테스트**: 빌드 후 자동 테스트 실행
- **자동 배포**: 테스트 통과 시 자동 배포 (선택적)

### 10.3 롤백
- **롤백 계획**: 배포 실패 시 이전 버전으로 롤백 가능
- **데이터베이스 마이그레이션**: 롤백 가능한 마이그레이션 전략
