# 로보어드바이저 제품 요약 (첫 목적 기준)

**목적**: "나 대신 투자해주는 고수익 로보어드바이저"를 한 축으로 기획·개발 현황·필요 작업을 한 문서에서 참조한다.

---

## 1. 한 줄 정의

**나 대신 투자해주는 고수익 로보어드바이저** — 사람 개입 없이 퀀트 엔진 기반 자동 매매 (MDD -15% 이내, CAGR 30%+ 목표).

---

## 2. 핵심 사용자 플로우

1. **진입**: 랜딩(/) → 로그인 또는 회원가입
2. **온보딩**: 설정에서 계좌·API 연결 → 거래 설정(최대 투자금·단기/중기/장기 비율) + **자동투자 ON**
3. **일상**: 대시보드에서 자산·자동투자 상태 확인 → 자동투자 현황에서 파이프라인·시그널 확인 → (선택) 백테스트로 전략 검증

```
랜딩 → 로그인/가입 → 설정(계좌·자동투자 ON) → 대시보드·자동투자 현황
```

---

## 3. 완료 / 부족 / 필요 요약

| 구분 | 내용 |
|------|------|
| **완료** | 인증·계좌·주문·전략·설정(API)·파이프라인·시그널·뉴스·백테스트·트리거·배치·4단계 파이프라인·로보 엔진·React 화면(대시보드·설정·자동투자 현황·백테스트·배치 등)·대부분 API 연동. **로보 플로우 명확화**: 랜딩 한 줄 문구("나 대신 투자해주는 고수익 로보어드바이저")·CTA, 대시보드/자동투자 현황 빈 상태 "설정에서 계좌를 연결해주세요" + [설정으로 가기], 자동투자 OFF 시 카드 내 안내 + [설정으로 가기], 설정 탭 계좌 0개 시 [계좌 설정으로 가기]. |
| **부족** | 실시간 차트·성과 분석·반응형·모바일 등 추가 UX(선택). |
| **필요 개발** | (P0·P1 연동 완료 후) P2 뉴스 수집·포트폴리오 확장, P3 분석/시장데이터(선택). |

---

## 4. 화면–API 매핑 보완 (우선순위)

| 우선순위 | API | 보완 내용 |
|----------|-----|-----------|
| P0 | PUT `/api/v1/settings/{accountNo}` | Settings 화면에서 거래 설정 저장 시 호출 |
| P0 | 로보 백테스트 3종 | Backtest 페이지: runRoboBacktest, getLastPreExecution, collectUsDaily |
| P1 | PUT `/api/v1/auth/mypage` | MyPage 프로필 수정 폼 제출 시 호출 |
| P1 | POST `/api/v1/orders` | Orders/전략 화면에서 수동 주문 시 호출 |
| P2 | POST `/api/v1/news/collect` | 뉴스 화면 "수집 실행" 버튼 |
| P2 | 트레이딩 포트폴리오 date/latest/generate | 포트폴리오 화면 날짜별·최신·수동 생성 |
| P3 | 분석·시장데이터 API | 전용 화면/위젯 추가 시 연동 |
