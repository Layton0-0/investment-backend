# 전략·계산 방식 통합 문서 및 버전 스택 계획 (기간별 전략 포함)

## 개요

프로젝트의 모든 투자 전략·계산 방식을 한 문서에 통합하고, 전략 업데이트 시 갱신·버전 스택(실패/교훈 포함)으로 경험을 쌓으며, **나라별·분야별·기간별**로 정리해 정확도를 높이는 구조를 설계합니다.

---

## 1. 통합 문서 신설 (단일 소스)

**권장 경로**: `docs/02-architecture/00-strategy-registry.md`

**문서 구조 (나라별·분야별·기간별 정확도 반영)**:

| 대분류 | 내용 |
|--------|------|
| **1. 메타** | 현재 전략 문서 버전(예: v1.0), 최종 갱신일, 코드/설정 참조 경로 |
| **2. 공통** | 수익·리스크 목표(MDD, CAGR), 켈리 공식(Half-Kelly)·변동성 돌파 기본 수식, ATR 포지션 사이징·변동성 역가중 수식, 용어 정의 |
| **3. 나라별 (KR / US)** | 유니버스 필터(공통 Liquidity + KR: Sector RS / US: Post-Earnings Drift), 시그널(KR: 이격도·변동성 돌파 k 동적·수급 강도 / US: 듀얼 모멘텀·퀄리티-성장·VAA 변형), 청산(ATR Trailing Stop·Time-Cut) — 각 항목별 수식·파라미터·설정 키 |
| **4. 기간별 전략 (단기 / 중기 / 장기)** | **비중·목표 수익률·대상·매수 필터·매도/리스크**를 기간별로 명시. (12-auto-investment-strategy §3·§4.1 기준) |
| **5. 분야별** | 파이프라인 단계(유니버스→시그널→자금관리→실행)별 정리; 향후 섹터/테마(반도체, AI, 2차전지 등) 확장 |
| **6. 계산 수식·파라미터 일람** | 팩터/전략별 수식, `application.yml` 키, 대응 서비스/메서드 표 |
| **7. 버전 스택 (경험 축적)** | 버전·일자·적용 시장/분야/기간·변경 요약·결과(성공/실패/미검증)·교훈 |

기존 [12-auto-investment-strategy.md](docs/02-architecture/12-auto-investment-strategy.md)의 상세 수치·파라미터는 이 통합 문서를 단일 소스로 두고, 12에서는 "상세는 00-strategy-registry 참조"로 정리합니다.

## 2. 기간별 전략 상세 (통합 문서 §4 반영 내용)

통합 문서 **§4 기간별 전략**에는 아래를 그대로 반영합니다. (출처: 12-auto-investment-strategy §3·§4.1)

| 구간 | 비중 | 목표 수익률 | 대상 | 매수 필터 | 매도/리스크 |
|------|------|-------------|------|-----------|-------------|
| **단기** | 20% | 주간 5%+ / 월간 20%+ | 미국 3배 레버리지 ETF(TQQQ, SOXL), 한국 테마 대장주 | 유동성(한국 5일 평균 거래대금 >1,000억, 미국 >5억 달러), RSI(14)>60 & MACD>Signal, 수급(기관/외국인 순매수 2일+ & 체결강도 120%+) | Trailing Stop: 고점 대비 -3% 시 기계적 매도 |
| **중기** | 40% | 분기 15%+ | 주도 섹터(반도체, AI, 2차전지, 바이오 등) 1등주 | 듀얼 모멘텀: 3개월 수익률 S&P500/KOSPI 대비 상위 10%, EPS 성장(YoY)>20%, PEG<1.5, 주가가 20·60일선 위 정배열 | 월 1회 리밸런싱, 모멘텀 순위 하락 시 교체; 개별 -10% 도달 시 손절 |
| **장기** | 40% | 연 25%+ (복리 극대화) | 경제적 해자 확실한 글로벌 1위 (미국 빅테크 위주) | 퀄리티: ROE>20%, OPM>25%; Rule of 40(매출증가율+영업이익률>40%); MDD -15%~-20% 시 분할 매수 트리거 | 펀더멘털 훼손 시에만 매도; 상대적 손절 없음(저가 시 추가 매수) |

- **시드 배분 요약**: 슈퍼 그로스(장기) 40%, 추세 추종(중기) 40%, 알고리즘 트레이딩(단기) 20%.
- 기간별 전략이 **나라별(KR/US)**·**파이프라인 단계**와 교차할 때(예: 단기-KR 테마주 필터, 장기-US 빅테크) 통합 문서에서 해당 조합별 수식·임계값을 명시해 정확도를 높입니다.

## 3. 버전 관리 및 스택 (실패 참고·경험 축적)

- 통합 문서 말미 **§7 버전 스택**에 전략 버전 단위 테이블 유지.
- **컬럼 예시**: 버전 | 일자 | 적용 시장(나라) | 적용 분야/기간(단기·중기·장기 등) | 변경 요약 | 결과(성공/실패/미검증) | 교훈·비고
- 전략·팩터·계산 방식 변경 시마다 한 행 추가; 백테스트/실전 결과가 있으면 결과·교훈을 기입해 실패 사례를 참고할 수 있게 함.
- (선택) `plans/strategy-versions/YYYYMMDD-HHmm_전략-vX.Y.md` 형태로 해당 시점 스냅샷 보관.

---

## 4. 전략 업데이트 시 문서 갱신 규칙

- **규칙 추가**: 전략·팩터·계산 방식 변경 시 **전략 통합 문서**(`docs/02-architecture/00-strategy-registry.md`)를 갱신하고, **버전 스택**에 새 버전·변경 요약·결과·교훈을 추가한다.
- **개발 현황 연동**: 02-development-status.md에서 전략 관련 항목 완료 시 "전략 통합 문서 반영 (버전 x.y)" 문구 추가.

---

## 5. 구현 시 작업 순서

1. **`docs/02-architecture/00-strategy-registry.md` 생성** — §1~§7 초안 작성(§4 기간별 전략 표 포함), §7 버전 스택 초기 1행 기입.
2. **12-auto-investment-strategy.md 수정** — 상세는 00-strategy-registry 참조로 정리, 문서 변경 이력에 "전략 통합 문서 분리·기간별 전략 반영" 추가.
3. **갱신 규칙 반영** — development-status.mdc(또는 전략 전용 규칙)에 "전략/팩터 변경 시 00-strategy-registry 갱신·버전 스택 추가" 문구 추가.
4. **(선택)** `plans/strategy-versions/` 디렉터리 및 스냅샷 파일명 규칙 명시.
