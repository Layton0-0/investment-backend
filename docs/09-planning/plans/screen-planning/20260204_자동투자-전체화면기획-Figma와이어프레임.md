## 전체 화면 목록(초안, 문서에 확정)

- 공통(모든 역할)
  - 인증: 로그인, 회원가입, 계좌 인증(verify-account), 로그아웃
  - 전역: 헤더/메뉴/모의-실 전역 탭(`serverType`), 401/403/404/500, 빈상태/로딩/에러 패턴
- 일반 사용자(User)
  - 대시보드(모의/실 구역 요약 + 빠른 액션)
  - 자동투자 현황(4단계 카드 + 시그널/포지션 목록 + "왜 주문이 안 나갔는가" 가드레일 표시)
  - 전략(KR/US): 목록/상세/상태 변경/파라미터 보기
  - 뉴스·이벤트: 목록/상세/필터(원천/시장/기간/종목)
  - 포트폴리오: 보유종목, 트레이딩 포트폴리오(일별 추천)
  - 주문·체결: 목록/상세/미체결 취소
  - 백테스트: 파이프라인/로보(간단+고급)/결과 비교
  - 설정: 계좌·API, 거래 설정(비율/한도/자동투자/로보), 리스크 설정(표시/설명 중심)
- 운영자(Ops)
  - 스케줄 현황: Job 목록/최근 실행/성공·실패/"지금 실행"/실행 이력
  - 데이터 파이프라인 상태: 원천별 수집 상태(DART/SEC/KRX/US)·최근 데이터 기준일·오류 요약
  - 알림센터: 미체결 경고, 리스크 게이트 발동, 일일 손실 한도, 장애/RateLimit, Discord 알림 전달 상태(ACK/해제 플로우)
  - 리스크 리포트: 노출(시장/전략/기간), MDD/손실한도 추이, 게이트에 의한 축소 내역
  - 모델/예측 상태: AI health/model-ready, 최근 학습/버전(표시), 예측 호출 실패율
  - 감사 로그(경량): 설정 변경/수동 트리거/실계좌 가드 차단 이벤트
  - 시스템 헬스: 외부 API/DB/Redis/Prediction-service 상태 요약

## 핵심 상호작용 원칙(요약)

- 전역 `serverType` 탭은 **URL 쿼리로 상태 유지**하고, 모든 내부 링크가 이를 보존.
- "자동투자 ON"은 통합 오케스트레이션 개념으로 설명(문서 §6.1.1/§6.2와 정합).
- 실제 주문 관련 위험 행동은 **2중 확인**
  - UI에서 가능한 범위: 명확한 경고/차단 이유/다음 액션(설정 저장, 서버 플래그, 계좌/토큰 상태)
  - Ops 전용: "실계좌 자동 실행 가드(allow-real-execution)" 상태를 읽기 전용으로 표시
