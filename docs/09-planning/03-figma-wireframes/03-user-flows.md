# 핵심 유저 플로우

## 신규 사용자 권장 경로

1. **랜딩(/)**: "나 대신 투자해주는 로보어드바이저" 안내 → [시작하기] → `/signup` 또는 [로그인] → `/login`
2. **가입 후**: 설정(`/settings`)에서 계좌·API 연결 → 거래 설정(최대 투자금·단기/중기/장기 비율) + **자동투자 ON** → [저장]
3. **일상**: 대시보드(`/dashboard`)에서 자산·자동투자 상태 한눈에 확인 → 자동투자 현황(`/auto-invest`)에서 파이프라인·시그널 확인. (선택) 백테스트(`/backtest`)로 전략 검증.

요약: **랜딩 → 로그인/가입 → 설정(계좌·자동투자 ON) → 대시보드·자동투자 현황**

---

## 1. 온보딩(회원가입·계좌 연결)

1. 사용자 → `/signup` 접근.
2. 서버 타입 선택(모의/실계좌).
3. API Key·Secret·계좌번호 입력.
4. [계좌 인증] 클릭 → `POST /api/v1/auth/verify-account` (토큰 발급 성공 시 인증 완료).
5. 비밀번호·사용자명 등 나머지 입력 후 회원가입 완료.
6. 로그인 → 대시보드(`/`). 계좌 미등록 시 빈 상태 + "설정에서 API 키 등록" CTA.

## 2. 자동투자 활성화

1. 사용자 → `/settings` (serverType 유지).
2. 계좌·API가 이미 등록된 상태에서 "자동투자 설정" 블록으로 스크롤.
3. "모의계좌 | 실계좌" 중 하나 선택 → 해당 계좌의 거래 설정 폼 표시.
4. 최대 투자금액·단기/중기/장기 비율 입력.
5. **자동 매매** 토글 ON. (선택) **로보 어드바이저** 토글 ON.
6. [저장] → `PUT /api/v1/settings/accounts` 또는 거래 설정 API. 성공 시 "저장되었습니다." 표시.
7. 실제 주문이 나가려면 서버에서 `PIPELINE_AUTO_EXECUTE=true` 필요. 실계좌는 추가로 `PIPELINE_ALLOW_REAL_EXECUTION=true` 필요.

## 3. 수동 트리거(스케줄 "지금 실행")

1. 운영자 → `/batch` (스케줄 현황).
2. Job 목록에서 대상 Job 선택.
3. [지금 실행] 클릭 → 트리거 API 호출(예: `POST /api/v1/trigger/...`).
4. 결과: 성공/실패 메시지 또는 Job 실행 ID. 실행 이력 테이블에 반영.

## 4. 백테스트 실행

1. 사용자 → `/backtest`.
2. 모드 선택: "4단계 파이프라인 백테스트" | "로보어드바이저 백테스트".
3. **4단계**: 기간·시장·전략·초기자본 입력 → [실행] → `POST /api/v1/backtest`. 결과: 메트릭·수익 곡선·거래 목록.
4. **로보**: 간단(기간·초기자본) 또는 고급(모멘텀·MA·Top N 등) 입력 → [실행] → `POST /api/v1/backtest/robo`. 결과: 해석·메트릭·수익 곡선 vs 벤치마크·리밸런싱 이력.

## 5. 주문 취소(미체결)

1. 사용자 → `/orders` (serverType 유지).
2. 주문 목록에서 상태가 "미체결(PENDING)"인 행 선택.
3. [취소] 클릭 → 확인 모달 → `DELETE /api/v1/orders/{orderId}`.
4. 목록 갱신 또는 토스트 "취소 요청되었습니다."

## 6. 알림 처리(Ops)

1. 운영자 → `/ops/alerts`.
2. 알림 목록: 미체결 경고·리스크 게이트 발동·일일 손실 한도·장애 등.
3. 항목 선택 → [확인(ACK)] 또는 [해제] → 상태 갱신. (API 정의 시 연동)

## 7. "왜 주문이 안 나갔는가" 확인(자동투자 현황)

1. 사용자 → `/auto-invest`.
2. 4단계 카드·시그널/포지션 테이블로 파이프라인 상태 확인.
3. 가드레일 안내: 자동 매매 OFF, auto-execute=false, 일일 손실 한도 초과, 리스크 게이트, 계좌/토큰 미등록 등 — [05-states-and-guardrails.md](05-states-and-guardrails.md)에 따라 UI에 문구·다음 액션 링크 표시.
