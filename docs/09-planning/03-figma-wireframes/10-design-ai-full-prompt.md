# 디자인 AI 전체 프롬프트 (단일 입력용)

**사용 방법**: 아래 전체 내용을 Figma Make·Figma AI·기타 디자인 AI 채팅에 **붙여넣기**만 하면, 모든 화면과 UI/UX 워크플로우가 반영된 와이어프레임 설계를 요청할 수 있습니다.

**글자 수 제한이 있는 경우**: 0~4절 → 5~7절 → 8~10절 순서로 나눠 붙여넣거나, 먼저 "요약본" 섹션만 넣고 이어서 상세 블록을 붙여넣으세요.

## 요약본 (먼저 넣을 때)

- **제품**: 한국/미국 주식 통합 퀀트·로보어드바이저. 4단계 파이프라인 + 로보(ETF). 전역 탭 모의계좌|실계좌.
- **디자인 원칙**: 정보 밀도·명확성·운영 제어 우선. 비시각적 플레어(로우파이 와이어프레임).
- **페이지**: 00-IA, 01-Auth, 02-Dashboard, 03-AutoInvest, 04-Strategy, 05-News, 06-Portfolio, 07-Orders, 08-Batch, 09-Backtest, 10-Settings, 11-Ops, 12-TaxReport, 13-Components.
- **추가 프레임**: 연말 세금·리포트, 포트폴리오 내 세금·수수료 뷰, 킬스위치·시스템 헬스(Admin/대시보드).
- **워크플로우**: 진입 → 구성 요소 → 사용자 액션 → 결과/다음 화면 → 로딩·빈 상태·에러·가드레일. 모든 화면에 적용.

## 0. 프로젝트·디자인 원칙

- **제품**: Investment Choi — 로보어드바이저형 자동투자 시스템(한국/미국 주식 통합). 한국투자증권 Open API 연동.
- **핵심 로직**: 4단계 파이프라인(유니버스 → 시그널 → 자금관리 → 매매실행) + (선택) 로보(ETF) 단계.
- **전역 상태**: **모의계좌(serverType=1) | 실계좌(serverType=0)** 탭을 모든 인증 후 화면에 표시. URL 쿼리로 유지.
- **권한**: `User`(투자/설정/조회), `Admin`(User + 스케줄 트리거·데이터·알림·리스크·모델·감사·헬스·킬스위치).

**디자인 원칙(기획요청 §8 반영)**  
- **Information density**: 정보 밀도 우선. 한 화면에서 계좌·전략·리스크·주문 요약을 파악 가능하게.  
- **Clarity**: 명확한 라벨·상태·다음 액션. 모호한 표현 금지.  
- **Operational control**: 포트폴리오·전략 성과·리스크 메트릭·트레이드 블로터·**세금·수수료 영향**·**시스템 헬스·킬스위치** UI로 운영 제어 가능.  
- **Not visual flair**: 화려한 비주얼보다 기능·가독성·일관성. 로우파이 와이어프레임 스타일 유지.

## 4. 가드레일(안전장치) UI 규칙

다음 조건은 **명확한 문구 + 다음 액션 링크/버튼**으로 표현:

- **계좌 미등록**: "모의계좌를 등록해주세요" / "실계좌를 등록해주세요" + [설정에서 등록] CTA
- **자동 매매 OFF**: "주문이 나가지 않습니다. 설정에서 자동 매매를 켜세요." + 설정 링크
- **서버 Dry-Run(auto-execute=false)**: "현재 서버는 Dry-Run 모드입니다. 실제 주문 실행은 서버 설정(PIPELINE_AUTO_EXECUTE)이 필요합니다." (읽기 전용)
- **실계좌 자동 실행 차단(allow-real-execution=false)**: "실계좌 자동 실행은 서버 설정(PIPELINE_ALLOW_REAL_EXECUTION)으로만 허용됩니다." (Admin 읽기 전용)
- **리스크 게이트**: "리스크 게이트가 적용되어 신규 매수 비중이 축소되었습니다."
- **일일 손실 한도**: "오늘 일일 손실 한도에 도달하여 신규 매수가 중단되었습니다." + 설정 안내
- **Rate limit**: "요청 한도를 초과했습니다. 잠시 후 다시 시도해주세요."
- **외부 API 장애**: "일부 데이터를 불러오지 못했습니다" + [재시도]

**2중 확인 모달** 사용: 자동 매매 ON, "지금 실행", **킬스위치(자동 실행 중지)** 등 실제 주문/시스템에 영향을 주는 행동.

**읽기 전용**: auto-execute, allow-real-execution, 서버 전용 리스크 파라미터는 UI에서 값 변경 컨트롤 두지 않음.

## 5. 화면별 상세 + 전체 워크플로우

각 화면에 대해: 진입 → 화면 구성 → 사용자 액션 → 액션별 결과 → 예외(Loading/Empty/Error/가드레일).

### 5.1 Auth (01-Auth)

- **진입**: URL `/login`, `/signup`. 전제: 없음(비인증 접근).
- **화면 구성**: 로그인 — 이메일/ID·비밀번호, [로그인], 회원가입 링크. 회원가입 — 서버 타입(모의/실), API Key, Secret, 계좌번호, [계좌 인증], 비밀번호, 사용자명 등, [가입].
- **사용자 액션**: [로그인] 제출; [회원가입] 링크 클릭; [계좌 인증] 클릭; [가입] 제출.
- **액션별 결과**: 로그인 성공 → 토큰 저장, `/` 리다이렉트(serverType=1). 계좌 인증 성공 → "인증 완료" 표시. 가입 완료 → 로그인 페이지 또는 자동 로그인. 로그인 실패 → 401 메시지. 인증 실패 → "API 키 또는 계좌번호를 확인해주세요."
- **예외**: 401 "아이디 또는 비밀번호가 올바르지 않습니다." Rate limit "요청이 많습니다. 잠시 후 다시 시도해주세요."

### 5.2 Dashboard (02-Dashboard)

- **진입**: URL `/`. 전제: 로그인.
- **화면 구성**: QuickAction 카드 6개(국내 전략, 미국 전략, 뉴스, 포트폴리오, 주문·체결, 설정). 모의계좌 구역·실계좌 구역 각각: 자동투자 상태 카드, 계좌 요약, Stat 카드 4개, 잔고 카드, 보유 종목 테이블, 최근 주문 테이블. (Admin 또는 대시보드) **킬스위치** 블록: 자동 실행 중지 버튼 + 상태 표시.
- **사용자 액션**: QuickAction 카드 클릭; 모의/실 탭 전환; 킬스위치 [중지] 클릭(Admin); "자동투자 현황 자세히 보기" 링크.
- **액션별 결과**: QuickAction → 해당 경로로 이동(serverType 유지). 킬스위치 → 확인 모달 → API 호출 → 상태 갱신. 링크 → `/auto-invest`.
- **예외**: Loading(잔고·보유·주문 병렬). Empty: 계좌 0개 "계좌를 등록하여 투자를 시작하세요" + [설정]. 계좌 미등록·자동투자 OFF 시 가드레일 문구 + 설정 CTA.

### 5.3 AutoInvest (03-AutoInvest)

- **진입**: URL `/auto-invest`. 전제: 로그인.
- **화면 구성**: 4단계 파이프라인 카드 4개(유니버스 KR·US, 시그널 KR·US, 자금 배분, 보유 포지션). 시그널 테이블. 보유 포지션 테이블. 가드레일 안내 영역.
- **사용자 액션**: (선택) 시그널·포지션 필터/페이징; 가드레일 문구 내 "설정" 링크 클릭.
- **액션별 결과**: 필터 → 목록 갱신. 설정 링크 → `/settings`.
- **예외**: Loading(파이프라인·시그널·포지션). Empty(시그널 0·포지션 0). Error(API 실패). 가드레일: 자동 매매 OFF, auto-execute, 일일 손실 한도, 리스크 게이트, 계좌 미등록 — 문구 + 다음 액션 링크.

### 5.4 Strategy KR / US (04-Strategy)

- **진입**: URL `/strategies/kr`, `/strategies/us`. 전제: 로그인. KR=모의계좌, US=실계좌 자동 사용.
- **화면 구성**: 단기/중기/장기 전략 카드 또는 테이블(상태 배지 ACTIVE/STOPPED/PAUSED, 비중, 최대/최소 금액, 성과). 유니버스/시그널 요약(API 제공 시).
- **사용자 액션**: [활성화], [중지] 버튼; (선택) 전략 상세 링크.
- **액션별 결과**: 활성화/중지 → PUT 또는 POST API → 목록 갱신. 상세 → 전략 상세 화면 또는 모달.
- **예외**: Loading, Empty. 계좌 미등록 "모의계좌를 등록해주세요" / "실계좌를 등록해주세요" + 설정 CTA.

### 5.5 News (05-News)

- **진입**: URL `/news`. 전제: 로그인.
- **화면 구성**: 필터(원천 Fact/Speed/Buzz, 시장, 기간, 종목). 목록 테이블(제목, 원천, 시장, 종목, 수집 시각, 감정/중요도). (선택) [수집 실행] 버튼.
- **사용자 액션**: 필터 변경; [수집 실행] 클릭.
- **액션별 결과**: 필터 → GET /api/v1/news 쿼리 갱신. 수집 실행 → POST /api/v1/news/collect → 성공/실패 메시지.
- **예외**: Loading, Empty, Error.

### 5.6 Portfolio (06-Portfolio)

- **진입**: URL `/portfolio`. 전제: 로그인.
- **화면 구성**: 보유 종목 테이블(종목, 시장, 수량, 평균가, 현재가, 평가금액, 평가손익). 트레이딩 포트폴리오: 거래일 선택, 추천 종목 테이블(진입가, 손절가, 목표가). **세금·수수료 영향 뷰**: 수수료·세금 영향 요약(라벨·숫자·간단 설명).
- **사용자 액션**: 거래일 선택; (선택) 최신 목록·수동 생성 버튼.
- **액션별 결과**: 날짜 선택 → GET /api/v1/trading-portfolios/{date}. 수동 생성 → POST generate → 목록 갱신.
- **예외**: Empty(보유 0·해당일 포트폴리오 없음). Error(API 실패).

### 5.7 Orders (07-Orders)

- **진입**: URL `/orders`. 전제: 로그인. serverType 유지.
- **화면 구성**: 필터 바(기간, 상태, 시장). 주문 테이블(주문일시, 종목, 시장, 매수/매도, 수량, 가격, 상태, 체결가). 미체결 행에 [취소] 버튼.
- **사용자 액션**: 필터 적용; [취소] 클릭.
- **액션별 결과**: 필터 → GET /api/v1/orders 쿼리 갱신. [취소] → 확인 모달 → DELETE /api/v1/orders/{orderId} → 목록 갱신 또는 토스트 "취소 요청되었습니다."
- **예외**: Loading, Empty, Error. 취소 실패 시 토스트 또는 인라인 메시지.

### 5.8 Batch (08-Batch)

- **진입**: URL `/batch`. 전제: 로그인. "지금 실행"은 Admin만 활성.
- **화면 구성**: Job 목록 테이블(Job 이름, cron, 마지막 실행, 성공/실패 횟수, [지금 실행] 버튼).
- **사용자 액션**: [지금 실행] 클릭.
- **액션별 결과**: 확인 모달(실제 주문 가능 시 경고) → POST /api/v1/trigger/... → 성공/실패 메시지 또는 Job 실행 ID. 실행 이력 반영.
- **예외**: User는 "지금 실행" 비활성 또는 숨김. Loading, Error.

### 5.9 Backtest (09-Backtest)

- **진입**: URL `/backtest`. 전제: 로그인.
- **화면 구성**: 모드 선택 "4단계 파이프라인 백테스트" | "로보어드바이저 백테스트". 4단계: 기간·시장·전략·초기자본, [실행]. 로보: 간단(기간·초기자본) / 고급(모멘텀·MA·Top N·리밸런싱·수수료/슬리피지), [실행]. 결과: 메트릭 카드, 수익 곡선 placeholder, 거래 목록. 로보 결과: 해석, 메트릭, 수익 곡선 vs 벤치마크, 리밸런싱 이력.
- **사용자 액션**: 모드 선택; 4단계/로보 폼 입력; [실행] 클릭.
- **액션별 결과**: [실행] → POST /api/v1/backtest 또는 POST /api/v1/backtest/robo → 결과 렌더링. (선택) GET last-pre-execution → 실행 전 백테스트 요약 표시.
- **예외**: Loading(실행 중). Empty(실행 전). Error(API 실패·warningMessage).

### 5.10 Settings (10-Settings)

- **진입**: URL `/settings`. 전제: 로그인.
- **화면 구성**: 계좌·API 연결(모의/실 세그먼트, API Key, Secret, 계좌번호, [저장]). 자동투자 설정: 등록 계좌 0개 → 빈 상태 + [계좌 설정으로 가기]. 1개 또는 2개 → 해당 타입 폼(최대/최소 투자금액, 단/중/장 비율, 자동 매매 토글, 로보 토글, [저장]). 로보 ON 시 자동투자 ON 연동 안내. 서버 가드(auto-execute, allow-real-execution) 읽기 전용 안내.
- **사용자 액션**: 세그먼트 선택; API·계좌 입력; [저장](계좌); 거래 설정 입력·토글; [저장](거래 설정); [계좌 설정으로 가기] 클릭.
- **액션별 결과**: 계좌 저장 → PUT /api/v1/settings/accounts. 거래 설정 저장 → PUT /api/v1/settings/{accountNo}. 성공 → "저장되었습니다." 인라인. 로보 ON 시 자동투자 ON 연동. CTA → #accountsForm 또는 설정 상단.
- **예외**: Empty(계좌 0개). 비율 합=1 검증 실패. 저장 실패 에러 메시지.

### 5.11 Ops (11-Ops)

- **진입**: URL `/ops/data`, `/ops/alerts`, `/risk`, `/ops/model`, `/ops/audit`, `/ops/health`. 전제: 로그인, 역할 Admin.
- **화면 구성**: 데이터 파이프라인 — 원천별(DART/SEC/KRX/US) 수집 상태 카드/테이블. 알림센터 — 알림 목록, [ACK]/[해제]. 리스크 리포트 — 필터, 차트 placeholder, 테이블. 모델/예측 — 상태 배지, 버전, 실패율. 감사 로그 — 테이블(일시, 이벤트, 사용자·계좌 마스킹). **시스템 헬스** — 서비스별 상태(외부 API·DB·Redis·Prediction). **킬스위치** — [자동 실행 긴급 중지] 버튼, 실행 중/중지됨 상태(읽기 전용).
- **사용자 액션**: 알림 [ACK]/[해제]; 리스크 필터 변경; 킬스위치 [중지] 클릭.
- **액션별 결과**: ACK/해제 → 상태 갱신. 킬스위치 → 확인 모달 → API → 상태 표시 갱신.
- **예외**: User는 Admin 메뉴 미노출. Loading, Error.

### 5.12 연말 세금·리포트 (12-TaxReport)

- **사용자 액션**: 기간/필터 선택; [CSV 내보내기], [PDF 내보내기] 클릭.
- **액션별 결과**: 필터 → 요약 갱신. 내보내기 → 파일 다운로드.

## 9. 전체 유저 플로우 요약

1. **랜딩** → [시작하기] → `/signup` 또는 [로그인] → `/login`
2. **가입** → 설정(`/settings`) 계좌·API 연결 → 거래 설정 + 자동투자 ON → [저장]
3. **일상** → 대시보드(`/`) 자산·자동투자 상태 확인 → 자동투자 현황(`/auto-invest`) 파이프라인·시그널 확인
4. **선택** → 백테스트(`/backtest`) 전략 검증; 주문·체결(`/orders`) 미체결 취소; 포트폴리오(`/portfolio`) 세금·수수료 뷰; 연말 세금·리포트(`/report/tax`) 조회·내보내기
5. **Admin** → 스케줄 현황(`/batch`) [지금 실행]; 알림센터(`/ops/alerts`) ACK; 시스템 헬스(`/ops/health`) 킬스위치·헬스 확인
6. **가드레일** → 계좌 미등록·자동 매매 OFF·Dry-Run·일일 손실 한도·리스크 게이트 시 문구 + 다음 액션(설정·재시도 등)
