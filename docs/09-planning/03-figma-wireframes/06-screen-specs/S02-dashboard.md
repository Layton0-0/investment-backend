# S02 — 대시보드

## 목적

로그인 후 첫 화면. 모의계좌·실계좌를 한 화면에서 구역으로 구분해 계좌 요약·자동투자 상태·빠른 진입 제공.

## 정보 구조

- **빠른 액션**: 국내 전략, 미국 전략, 뉴스·이벤트, 포트폴리오, 주문·체결, 설정(각 serverType 쿼리 포함).
- **모의계좌 구역**: 자동투자 상태 카드(ON/OFF, 유니버스 KR·US, 시그널 KR·US, 보유 포지션 수), 계좌 요약(국내/미국 보유 종목 수, 총 잔고), 통계 카드(총 자산, 보유 종목 수, 총 손익, 총 수익률), 계좌 잔고, 보유 종목 테이블, 최근 주문 테이블.
- **실계좌 구역**: 동일 구조, 실계좌 데이터만.
- **빈 상태**: 계좌 없음 시 "계좌를 등록하여 투자를 시작하세요" + [설정에서 API 키 등록]. 모의/실 중 해당 탭만 미등록 시 해당 구역에 "모의계좌를 등록해주세요" 등.

## 주요 상호작용

- 빠른 액션 클릭 → 해당 경로로 이동(serverType 유지).
- "자동투자 현황 자세히 보기" → /auto-invest.

## 상태/에러

- Loading: 잔고·보유·주문 병렬 로딩 시 스피너 또는 스켈레톤.
- Empty: 계좌 0개 또는 해당 타입 계좌 없음.
- Error: API 실패 시 에러 박스·재시도.

## 권한

- User, Ops 모두 접근.

## 연동 API

- AccountService.getMainAccount, getBalanceAndPositions, PipelineSummaryService.getSummary, 주문 목록(최근 N건).
