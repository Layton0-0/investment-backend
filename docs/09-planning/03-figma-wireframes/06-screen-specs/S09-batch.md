# S09 — 스케줄 현황

## 목적

스케줄러 Job 목록·최근 실행·성공/실패·"지금 실행"·실행 이력.

## 정보 구조

- Job 목록 테이블: Job 이름, cron 설명(한국어 실행 주기), 마지막 실행 시각, 총 실행/성공/실패 횟수, [지금 실행] 버튼.
- (선택) 실행 이력: Job별 최근 N회 실행 결과.

## 주요 상호작용

- [지금 실행] → 트리거 API(예: POST /api/v1/trigger/...) → 성공/실패 피드백. 2중 확인(실제 주문 가능 시).
- 페이지 로드 → GET /batch/api/jobs (실제 구현 경로).

## 상태/에러

- Loading, Error. 트리거 실패 시 메시지 표시.

## 권한

- User: 읽기·(정책에 따라) 지금 실행 제한 가능. Admin: 읽기·지금 실행 허용.

## 연동 API

- GET /batch/api/jobs, POST /api/v1/trigger/... (경로는 02-api-endpoints 참조).
