# S08 — 주문·체결

## 목적

주문 목록·체결 내역·미체결 취소.

## 두 테이블 구분

- **주문 및 체결 내역**: 본 시스템(TB_ORDERS)에 기록된 모든 주문 시도 — 수동 주문·파이프라인 자동 주문 포함. 성공·실패·대기·취소 모두 표시. 실패 건은 실패 사유(message) 표시.
- **한투 API 체결 내역 (최근 7일)**: 한국투자증권 API(주문체결조회)로 조회한, 증권사에 실제 전달된 주문·체결만 표시. 위 표에만 있고 여기 없으면 증권사에는 미전달(실패 등)된 주문임.

## 정보 구조

- 주문 목록 테이블: 주문일시(초 단위 가독성), 종목(국내는 종목명·해외는 코드), 시장, 매수/매도, 수량, 가격(통화·주당/총액·콤마), 상태, 사유(수동 주문/시그널 유형/실패 시 실패 사유), 체결가 등.
- 필터: 기간, 상태(PENDING/EXECUTED/CANCELLED 등), 시장.

## 주요 상호작용

- 필터 적용 → GET /api/v1/orders 쿼리 갱신.
- 미체결 행 [취소] → 확인 모달 → DELETE /api/v1/orders/{orderId}.

## 상태/에러

- Loading, Empty, Error. 취소 실패 시 토스트 또는 인라인 메시지.

## 권한

- User, Admin: 읽기, 본인 주문 취소 가능.

## 연동 API

- GET /api/v1/orders?accountNo=..., DELETE /api/v1/orders/{orderId}.
