# S12 — Admin 전용 화면 (Ops 페이지)

관리자(Admin)만 접근. User는 메뉴 미노출 또는 비활성.

## 데이터 파이프라인 상태 (/ops/data)

- **목적**: 원천별 수집 상태·최근 기준일·오류 요약.
- **정보**: DART, SEC, KRX, US 원천별 카드/행. 최근 수집 일시, 성공/실패, 오류 메시지 요약.
- **API**: (내부 또는 GET /api/v1/internal/data-status 등 정의 시.)

## 알림센터 (/ops/alerts)

- **목적**: 미체결 경고·리스크 게이트·일일 손실 한도·장애·Discord 전달 상태.
- **정보**: 알림 목록(시간, 유형, 요약, 계좌 마스킹). [확인(ACK)]·[해제].
- **상호작용**: ACK/해제 → 상태 갱신.

## 리스크 리포트 (/risk)

- **목적**: MDD·손실한도 추이·게이트에 의한 축소 내역.
- **정보**: 시장/전략/기간 필터. 차트/테이블(노출·MDD·한도 도달 이벤트).

## 모델/예측 상태 (/ops/model)

- **목적**: AI health·model-ready·최근 학습/버전·예측 호출 실패율.
- **정보**: 상태 배지, 버전, 실패율 %, 마지막 성공 시각.

## 감사 로그 (/ops/audit)

- **목적**: 설정 변경·수동 트리거·실계좌 가드 차단 이벤트.
- **정보**: 테이블(일시, 이벤트 유형, 사용자·계좌 마스킹, 요약).

## 시스템 헬스 (/ops/health)

- **목적**: 외부 API·DB·Redis·Prediction-service 상태 요약.
- **정보**: 서비스별 상태(정상/경고/다운), 마지막 체크 시각.

## 권한

- Admin만 접근. 연동 API는 각 기능별로 정의(내부 API 또는 기존 actuator·batch 확장).
