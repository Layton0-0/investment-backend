# 상태·가드레일(안전장치) UI 표현

## 1. 계좌·서버 타입

- **모의계좌(serverType=1) vs 실계좌(serverType=0)**: 전역 탭으로 명확히 구분. 실계좌 선택 시 위험 관련 문구(예: "실제 자금이 투입됩니다")를 설정·주문 화면에서 표시 가능.
- **계좌 미등록**: 해당 탭 선택 시 빈 상태. 문구: "모의계좌를 등록해주세요" / "실계좌를 등록해주세요" + [설정에서 등록] CTA.

## 2. 자동 주문 관련 가드

- **자동 매매 OFF**: 자동투자 현황·대시보드에서 "자동 매매 OFF" 표시. "주문이 나가지 않습니다. 설정에서 자동 매매를 켜세요." + 설정 링크.
- **auto-execute=false(서버/계정)**: 실제 매수/매도가 나가지 않음. **실제 설정값에 따라 조건부 표시**: 계정별 `pipelineAutoExecute === false`일 때만 대시보드/설정 근처에 "실제 주문 실행이 꺼져 있는 계좌가 있습니다. 설정에서 파이프라인 자동 실행을 켜면 주문이 실행됩니다." 등 읽기 전용 안내. 고정 문구 사용 금지.
- **allow-real-execution=false(서버/계정)**: 실계좌에 대한 자동 실행 차단. **실제 설정값에 따라 조건부 표시**. 고정 문구 사용 금지.

## 3. 리스크 게이트·일일 손실 한도

- **리스크 게이트 발동**: **실제 API(예: GET /api/v1/risk/summary)의 riskGateAllowsNewBuy === false일 때만** 자동투자 현황에 "신규 매수 제한: 리스크 게이트가 적용되어 있습니다." 등 표시. 고정 문구 사용 금지.
- **일일 손실 한도 초과**: 당일 신규 매수 중단. "오늘 일일 손실 한도에 도달하여 신규 매수가 중단되었습니다." + (선택) 일일 손실 한도 설정 위치 안내.

## 4. Rate Limit·API 장애

- **Rate Limit**: 주문·조회 과다 시 "요청 한도를 초과했습니다. 잠시 후 다시 시도해주세요." 토스트 또는 인라인 메시지.
- **외부 API 장애**: 한국투자증권·예측 서비스 등 장애 시 상태 표시(예: 시스템 헬스·알림). 사용자 화면에서는 "일부 데이터를 불러오지 못했습니다" + 재시도.

## 5. 2중 확인

- **실제 주문과 연결되는 행동**: 자동 매매 ON, (정책상) 수동 "지금 실행" 시 확인 모달. 예: "이 계좌에 대해 파이프라인을 지금 실행합니다. 실제 주문이 나갈 수 있습니다. 계속하시겠습니까?"

## 6. 표시 원칙 요약

- **읽기 전용으로만 표시할 항목**: auto-execute, allow-real-execution, 서버 전용 리스크 파라미터(VIX 임계값 등). UI에서 값을 변경하는 컨트롤은 두지 않음.
- **명확한 다음 액션**: 차단/경고 시 "설정에서 ~", "관리자에게 문의", "N분 후 재시도" 등 한 문장으로 안내.
